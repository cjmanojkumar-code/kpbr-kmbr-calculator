Rule/source notes

Municipality benchmark: the supplied KMBR scrutiny reports for Kottayam Municipality show A1 coverage “less than 65.00” and FSI “less than 4.00” with additional-fee wording under Rule 27. One report is a 345 m² plot and the other a 403 m² plot.
Panchayat Category I benchmark: the supplied Puthuppally Grama Panchayat report shows Category 1, A1 coverage less than 65.00 and FSI less than 4.00 with additional-fee wording. It also shows height up to 38.20 m under Rule 24(1A).
Panchayat Category II benchmark: the earlier accepted Kumarakom scrutiny benchmark shows the A1 Category II case used for the previous version.
F — Commercial benchmark: the newly supplied Kangazha Category II report is an accepted 57.70 m² built-up / 49.69 m² floor-area commercial building on a 962 m² plot. It records 60% coverage, FSI 3.50, access width 1.20 m, front 1.8/3.0 m, rear 1.0/1.5 m, sides 1.0/1.0 m, room height 3.0 m, exit width 1.2 m, maximum travel distance 30 m and DA ramp slope 0.08.

Setback values shown here are the A1 values observed in the supplied reports: front (1.8, 3), rear (1, 1.5), side (1,1), with some reports also showing Table 4A alongside Table 4. Project-specific provisos can change the applicable requirement, so the calculator flags these as “report-profile” values rather than claiming universal applicability.
